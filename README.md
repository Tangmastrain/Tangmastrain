## 关于我

写一些能立刻用上的小工具。主要围绕 **Windows 自动化、网络认证、批量处理**，也折腾 OpenWrt 与 HarmonyOS 设备；习惯把繁琐流程压缩成一条命令、一个托盘程序或一份清单。

> 代码以实用为先：能跑、能复现、出问题能查。
